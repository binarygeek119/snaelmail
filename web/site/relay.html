Host a Local Post Office Relay

Run your own Snaelmail relay to represent your city/region, host a public post office page, and help move mail across the network.

Important: No mail goes through the relay. A relay is only for adding a local post office location and managing its public presence.

What a Relay Does

  • Creates a local post office identity and public page.
  • Shows your city, photos, map, stamp, and about info.
  • Connects to the main Snaelmail site for directory listing and page sync.
  • Gives your community a local presence in the Snaelmail network.
  • Does not route or store mail - mail delivery is handled by the main Snaelmail service.

Requirements

  • A machine or VPS that can run Docker (or Go binary).
  • Port 8477/tcp open for the relay setup/dashboard UI (or access locally).
  • Outbound HTTPS access to https://snaelmail.org.
  • A Snaelmail account username + API key (generate in Account Settings).

Quick Start (Docker)

docker run -d \
  --name snaelmail-relay \
  -p 8477:8477 \
  -v snaelmail-relay-config:/config \
  ghcr.io/binarygeek119/snaelmail-relay:latest

Then open http://localhost:8477/ to complete the setup wizard.

Setup Wizard

  • Identity - generate keypair, enter Snaelmail username + API key.
  • Post Office Info - city, region/state, country, timezone, coordinates.
  • About - describe your local post office.
  • Images - upload city photos and optional city map.
  • Stamp - use default vintage stamp or upload your own.
  • Register - register with Snaelmail main site.

After Setup

Once registered, the relay dashboard shows notifications and mail activity. Use Sync to Main Site whenever you update your page info or images.
